## SkillBridge AI

SIH26044 Prototype

SkillBridge AI is an AI-powered Industry Career OS designed to
connect students, mentors, institutions and companies.

## Core Modules

1. AI Career Twin
2. Skill Intelligence
3. AI Skill Gap Analysis
4. AI Mentorship Matchmaker
5. 15-Minute Monthly Mentor Capsule
6. Micro-Internship Gig Board
7. Industry Challenges
8. Internship Matching
9. Placement Readiness
10. Experience Passport
11. Industry Collaboration
12. Career Analytics

Open terminal inside backend folder.

Install dependencies:

npm install

Start server:

npm start


Server:

http://localhost:5000


Health API:

http://localhost:5000/api/health


Student API:

http://localhost:5000/api/student


Mentor API:

http://localhost:5000/api/mentors


Gig API:

http://localhost:5000/api/gigs
